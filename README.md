# Banking Data Governance, Risk & Privacy Compliance Assessment

## Project Overview
This project explores how a fictional Canadian bank can classify and protect sensitive information, identify data security risks, and follow privacy governance principles.

## Objectives
- Classify banking information by sensitivity.
- Identify privacy and security risks.
- Recommend access controls and safeguards.
- Review data retention and protection practices.

## Tools and Frameworks
- Microsoft Excel
- PIPEDA privacy principles
- NIST Cybersecurity Framework 2.0

## Project Status
In progress.
